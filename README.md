# TrafficWise — Traffic Jam Awareness Project

A responsive, beginner-friendly website project explaining traffic congestion, its common causes, effects, and practical solutions.

## Features
- Responsive layout for desktop, tablet, and mobile
- Traffic-themed hero illustration made with CSS
- Sections about the problem, causes, and solutions
- Interactive commuter checklist with a live progress bar
- No build tools or installation required

## How to run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. That's it — the project runs locally.

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript

## Note
This is an educational awareness project. It does not provide live traffic data, navigation, or real-time congestion predictions.
